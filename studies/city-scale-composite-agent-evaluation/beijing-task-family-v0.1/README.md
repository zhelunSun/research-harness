## 只需先确认这一项

建议第一轮聚焦：**空间格局与潜在连通性**。

候选总体问题：北京既定研究区内，城市森林及关联植被景观呈现怎样的空间格局与潜在连通性，哪些空间差异和潜在薄弱环节值得进一步核查？

三个分析子问题与一个综合出口：

| 子问题 | 必须形成的成果候选 | 与其他任务的关系 |
| --- | --- | --- |
| T1 底图与空间格局 | 数据／类别口径说明、空间分布及其支持证据 | 为 T2、T3 提供同一底图和对象定义 |
| T2 核心栖息地形态 | 形态学定义下的对象图层、空间差异与解释 | 继承 T1；为 T3 提供同一组核心栖息地 |
| T3 潜在连通性 | 网络关系、潜在薄弱位置及网络／阻力证据边界 | 联用 T1、T2，按资料条件加入基质背景 |
| S 综合回答 | 哪些空间差异与薄弱环节有共同依据，哪些仍需补证 | 综合前三项，不按“多算几个指标”计成功 |

这不是四个独立统计样本。第一轮不要求实现完整监测指标目录；底图或尺度敏感性分析仅在有科学上可比的配对且另行获准时扩展，不是本轮必需回答。

## 为什么建议这个范围

现有指标矩阵已覆盖核心栖息地、廊道和基质；底图—形态—网络有明确配置衔接。详细冠层结构、物种和生态功能仍有明显资料或验证缺口。推荐先利用前者形成可检查的任务依赖，后者保留为扩展。

两项实物限制不能跳过：

1. 现有 Level 1 前景为乔木＋灌木＋草地＋湿地，不等于已经认可的狭义森林定义。生态对象、观察范围和时间口径需要确认，不能沿用文件名作判断。[CRITICAL-CHECK:scope-and-object-definition]
2. 在本机规范路径核查的底图和核心栖息地／网络制品尚缺；配置存在不代表可以立即复算。现有只读 Route B 协议检查仍可用，但不能作为这些科学子任务的参考答案。[CRITICAL-CHECK:scientific-acceptance]

## 与第二章、现行计划的关系

第二章在这些任务中应帮助智能体选择数据、形成分析、解释结果，同时检查证据边界；不只奖励发现错误或拒答。它已有单独的“两任务先行”工作，本包只提供北京任务族对接信息，不另选开发／确认任务，不重新请求已获授权的合理模型费用。

当前第二章先行任务不必等待北京重型资产恢复；公开完整任务可以先检验局部方法，但不能替代北京任务群的领域覆盖和跨任务评价。

第三章最低范围建议暂不包括：物种栖息证据、生态功能或管理效果验证、详细冠层高度与物候、完整指标目录、跨城市泛化。假如其中某项是你希望本章必须回答的核心问题，需要先调整此范围，而不是在实现后补成承诺。

相邻研究已有真实环境、多步骤和共享资料；跨子问题产品兼容、错误传播与总体问题完成程度是否构成可防守差异，仍待验证。[REF-MISSING:BTF-C5]
