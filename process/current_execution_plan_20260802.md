## 3. 研究内容二第一冲刺

### 推荐任务族

**城市森林制图精度验证与结论校准**。

使用现有 `TCE-S03` 作为任务来源，但不直接把其 gold checklist 暴露给 context selector
或 planner。将其拆为两个小型 fixture：

1. 分类图验证：独立参考数据、概率抽样、分类别精度、不确定性与结论边界；
2. 核心栖息地图验证：分类精度与生态有效性分离，证据不足时保持候选结论。

### 产物

1. 一个冻结的任务说明和失败条件；
2. 8--12 条任务相关候选 claim 的 source locator 队列；
3. 一个 human-reference contract 和一个 model-proposed contract；
4. 来源、适用性、冲突、风险和 answer-leakage 准入记录；
5. 两道任务的 B0--B5 可检查 fixture；
6. dry run 输出、机制 trace 和 claim-safe 解释。

### 通过条件

- 所有进入 contract 的 claim 均能定位到原文证据；
- contract 不包含完整验证方案或 gold 答案；
- B4/B5 至少能触发可观测的 add-validation、downgrade、ask 或 reject 行动；
- 错误、无关或缺失约束不会被机械执行；
- 结果同时报告行动变化、科学正确性和额外成本。

### 失败回退

- 若 B2/B3 与 B4 等效：把贡献收窄为结构化知识表示，不宣称 contract 机制；
- 若 B4 有效而 B5 无增益：保留软约束，删除不必要 enforcement；
- 若模型生成约束不稳定：保留人工校准的静态 contract 为毕业基本盘；
- 若专家成本过高：不宣称降低知识构建成本。
