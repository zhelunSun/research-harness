## 当前论断边界

- 不把“系统能够运行”直接写成结构化规划、验证或修复有效；
- 不把“工具数量增加”写成 runtime 或 Harness 科学贡献；
- 不把“知识能够检索”直接写成科学约束有效；
- 不把“模型同意规则”当作约束正确性的独立证据；
- 不把“地图精度较高”直接写成智能体可靠；
- 不把“大量日志”直接写成可用于强化学习的高质量轨迹数据集；
- 不把一次适应后得分提高写成 Agent 自进化，必须排除评分泄漏和回归；
- 不为保持故事线而改变下游仓库已有实验和结果的证据状态。

## 论断优先级

- **毕业基本盘**：E1、C1、C2、C3、B12、B23；
- **上探论断**：C4。它可以提高论文上限、职业相关性和公开项目价值，但不作为当前开题 50% 或毕业完成度的必要前提。

具体实验组、任务数量、统计方案和停止规则由后续章节执行计划维护，不写入 idea 版本。
