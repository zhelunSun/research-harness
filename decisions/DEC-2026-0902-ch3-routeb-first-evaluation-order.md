# DEC-2026-0902：Route B 作为第三项研究的首个评测实现

## 状态

- 决策状态：现行；研究者已明确接受。
- 接受时间：2026-09-02。
- 作用范围：第三项研究的首轮实施顺序。

## 决策

研究者接受 Route B 只读离线治理链作为第三项研究的首个最小评测实现。首轮从冻结制品、方法
版本、样本角色、分支依赖和禁止结论中选择 2–3 个可重放案例，先建立任务、环境、结果和评价器
接口，再开展最小跨系统比较。

本地植被斑块／核心栖息地分析与遥感空间网络分析（RSS）保留为接口稳定后的后续任务族。三者
共同服务于同一版本化城市森林任务环境，不是互斥的章级路线。

## 保留边界

- “只读离线”表示评测读取冻结制品和记录并禁止 GEE／Drive 写入，不表示原专业流程已经迁移为
  本地算法。
- manual 301 仍是人工校准／训练数据，不是独立验证。
- quick corridor baseline、完整 RSS、network-only 和 resistance-supported 状态继续分开。
- 本决策不冻结第三项研究的完整方法，不启动实验，不接受“城市级复合任务环境”的新颖性，也不
  支持智能体系统效果已经得到验证。
