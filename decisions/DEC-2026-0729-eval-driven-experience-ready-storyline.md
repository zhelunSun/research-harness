# DEC-2026-0729：第三项研究升级为可靠性评测，并采用 experience-ready 设计

## 状态

2026-07-29：Accepted at idea level。

本决策更新论文总体故事线和第三项研究角色，但不冻结正式中文提纲、
章节局部实验规模或具体实现框架。它部分替代
`DEC-2026-0717-three-layer-storyline.md` 中“第三项研究仅作为低标注制图
场景应用”的安排；前两项研究的“规划机制—约束机制”关系继续保留。

## 背景

既有“规划机制—约束机制—场景应用”主线能够串联 URSA、知识库和北京制图，
但第三项研究若只承担综合应用验证，存在三个问题：

1. 难以形成博士论文中相对独立的科学问题和方法贡献；
2. 容易与第一、二项研究各自应完成的局部机制验证发生重复；
3. 对当前 Agent 研究中的轨迹级评测、长期可靠性和经验学习衔接不足。

同时，已发表的 ExpertsRS 工作已经包含两项案例研究和 20 条请求的轻量
benchmark。新的第一项研究不能重复证明“多智能体能够完成遥感任务”，而应
研究结构化规划、验证、修复和轨迹化运行。

## 决策

论文总体故事线更新为：

> **规划机制 → 科学约束 → 可靠性评测**

其中：

1. 研究内容一负责需求形式化、类型化工具与工作流、验证和定向修复，并完成
   自己的局部机制实验；
2. 研究内容二负责将可追溯领域知识转化为能够改变智能体行为的科学约束，并
   完成匹配内容下的局部机制实验；
3. 研究内容三负责面向真实用户和城市森林遥感任务，建立任务级、轨迹级和
   用户级的可靠性评测方法与任务基准，完成系统级比较和失败诊断。

北京 2025 城市森林制图工作不再决定第三项研究的全部边界，而作为：

- 真实任务与制品来源；
- 连续交互和方法修改轨迹来源；
- 端到端综合案例；
- 评测任务与故障场景的领域基础。

总体技术设计采用以下长期原则：

> **轨迹原生、科学约束、评测驱动、经验可学习。**

“经验可学习”在当前论文中表示运行轨迹具有可复用、可评分、可进入后续学习
流程的结构，不等于承诺完成大规模强化学习或模型自训练。

## 第三项研究的最低独立贡献

第三项研究至少需要同时包含：

1. 可执行的城市森林遥感智能体任务基准；
2. 结合最终状态、执行轨迹和用户效用的可靠性评测方法；
3. 故障注入、失败类型和恢复行为分析；
4. 传统流程、通用智能体、结构化 URSA 和知识约束 URSA 的分层比较。

如果前述内容成立，第三项研究不依赖自进化或后训练也能够形成独立章节。

## 可选上探

在任务基准和评测器稳定后，可以研究小规模的：

> evaluation-guided harness adaptation

即根据失败轨迹提出运行配置、工具语义、重试策略、检查点或验证器的候选修改，
经隔离评测和回归门禁后决定是否接受。该扩展不允许：

- 取代第三项研究的评测基本盘；
- 与第二项研究的领域知识更新混为一谈；
- 使用训练集或评分器漏洞证明自我改进；
- 承诺开放式自进化或通用 Agent 网络。

## 明确不进入当前论文主线

- 通用或分布式 Agent runtime；
- 大规模 Agent RL、全参数训练或开放式自我改写；
- Agent 社会、跨组织 Agent 网络与协议治理；
- 将多模态遥感理解包装为世界模型贡献；
- 为追逐热点而新增与总科学问题无关的独立模块。

这些方向可以进入个人项目、实习研究或论文展望，但不得拖累学位论文基本盘。
