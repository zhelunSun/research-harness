# 跨仓同步提案

`upstream_proposals/` 保存来自下游仓库、可能影响本论文控制面的建议。每份文件都是待审提案，
而非已接受决策、当前执行计划或论文证据。

处理顺序：

1. 检查提案的目标、证据和风险；
2. 需要改变题目、章节角色、核心 claim、证据状态或优先级时，先取得研究者决定并新增 decision；
3. 只有接受后，才同步更新 `IDEA_VERSION.md`、`THESIS_STATE.md`、canonical idea、claims 和 evidence；
4. 未接受提案保留在本目录作为 provenance，不得被下游实现或聊天记录自动提升为论文事实。
