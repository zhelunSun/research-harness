# 博士学位论文工作提纲

> 版本：v0.2，2026-08-11
> 对齐 Idea：`idea-v2026.08.02`
> 状态：工作提纲；章标题采用已向导师汇报版本，节标题随方法证据迭代
> 题目：面向城市森林遥感制图的智能方法研究

## 研究内容一：基于多智能体的城市森林遥感工作流构建

1. 问题定义与总体框架
2. 多智能体分工与遥感工具体系
3. 可调整的分层规划与随执行更新的过程图
4. 运行检查、检查点局部恢复与轨迹记录
5. 实验设计与结果分析
6. 本章小结

本章内部方法链：`开放需求 → 分层规划 → 工具动作与真实反馈 → 过程图更新 → 检查点局部恢复或交付`。

原四状态 StateFlow 作为已发表基线保留；升级后的运行闭环是本章当前方法图。第一章只检查
工作流能否安全、完整、可追溯地运行，以及正确工具执行所需的底线不变量，不判断任务特定的
方法、阈值、证据和结论是否科学充分。

## 研究内容二：基于科学约束的城市森林遥感知识库构建

1. 问题定义与科学知识环境
2. 城市森林知识的证据化表示
3. 面向任务的科学约束生成
4. 科学约束的准入、执行与追踪
5. 实验设计与对比方法
6. 结果分析与适用边界
7. 本章小结

本章内部方法链：`Evidence Ledger → ScientificContract → Admission/Enforcement → Action Change`。

第二章负责判断“为什么科学上必须修改”，并输出修改计划、增加验证、询问、拒绝或结论降级；
它复用第一章的运行记录、过程图和检查点接口，不重复实现另一套失败恢复系统。

“科学知识环境”用于正文解释知识、证据、状态和工具语义共同构成的 Agent 外部环境；
章标题继续使用更简洁的“基于科学约束的……知识库构建”。

## 研究内容三：面向用户的城市森林遥感智能体系统验证

1. 面向用户的验证问题与总体框架
2. 真实任务、运行环境与过程轨迹构建
3. 对比系统与实验条件
4. 结果、过程、故障与用户评价指标
5. 系统比较与城市森林制图案例
6. 本章小结

本章内部评测链：`EvalTask → TrialTrace → Outcome → Evaluation`。系统验证至少覆盖
任务结果、工作流正确性、科学约束、故障恢复、人工干预和用户效用，不以单一地图
精度或综合展示替代验证。

## 三项研究的关系

```text
开放的城市森林遥感制图需求
  → 形成并运行可执行工作流
  → 以科学知识和证据约束关键决策
  → 在真实用户任务中验证完整系统
```

弱样本土地覆被制图作为专业工具、真实环境和比较基线进入各章，不单独破坏上述主线。
