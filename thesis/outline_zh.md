> 题目：面向城市森林遥感制图的智能方法研究

## 研究内容一：面向开放需求的多智能体遥感科学分析系统

1. 用户开放需求与多智能体系统总体框架
2. 多智能体角色协作与遥感科学工具体系
3. 遥感科学分析工作流生成与自动执行
4. 分析结果的解释、检查与交付
5. 动态规划、过程图更新与错误调节机制
6. 完整系统与增量机制的实验设计及结果分析
7. 本章小结

本章核心系统链：`开放需求 → 多智能体协作 → 工作流生成 → 工具调用与自动执行 → 可解释结果交付`。

本章增量机制链：`真实数据与工具反馈 → 动态规划与过程图更新 → 错误调节、检查点局部恢复或受控停止`。

ExpertsRS 的角色划分和基本工作流作为已发表基础保留。第一章先验证面向用户的完整分析链条，
再以同任务匹配条件评价动态规划和错误调节的增量作用。第一章检查工作流能否安全、完整、
可追溯地运行，以及正确工具执行所需的底线不变量，不判断任务特定的方法、阈值、证据和结论
是否科学充分。

## 研究内容二：面向智能体的遥感科学知识表示与推理

1. 问题定义与总体框架
2. 遥感科学知识的来源、适用条件与证据状态表示
3. 面向具体任务的知识组织与任务条件化表示
4. 知识—证据运行界面与面向任务的知识推理
5. 等知识内容、正负证据条件与分层匹配实验
6. 结果分析、失败条件与适用边界
7. 本章小结

本章内部方法链：`知识与证据底座 → 任务条件化科学知识表示 → 知识—证据运行界面 → 面向任务的知识推理 → 分层匹配评价`。

第二章研究当前知识和证据状态如何影响智能体围绕原始科学问题组织观测、分析、验证与解释，
使其能够补充证据、调整方法、收窄结论、询问或停止，但不预先规定唯一专家流程。它复用第一章
的运行记录、过程图和检查点接口，不重复实现另一套失败恢复系统。

“遥感科学知识表示与推理”是当前章级主术语；来源、适用条件、证据状态、验证义务和结论边界
是表示与推理需要处理的科学属性。具体表示、运行界面和作用效果仍待最小闭环验证。“认知环境”
只作解释性设计隐喻，`ScientificContract` 只作候选实现，均不替代可直接解释的研究对象。

## 研究内容三：面向城市森林遥感任务的智能体系统评测

1. 城市森林遥感任务特征与系统评测框架
2. 城市级跨环节指标及其依赖关系表示
3. 首组复合任务链、版本化环境与可重放条件构建
4. 对比系统、实验条件与可观察过程记录
5. 制品、来源、依赖、结论边界与故障处理评价
6. 跨系统比较、故障分析与城市级综合案例
7. 本章小结

本章内部评测链：`城市森林遥感任务 → 多阶段依赖与任务链 → 版本化试验 → 过程与结果记录 → 分层系统评价`。
系统验证至少覆盖跨步骤依赖、科学一致性、环境变化、故障处理和结果可追溯性，不以单一地图
精度、若干独立短任务或综合展示替代验证。用户／专家校准和经验驱动适应只作为候选增量。

## 三项研究的关系

```text
城市森林遥感任务
  → 由面向用户的多智能体系统形成并运行可执行工作流
  → 以任务条件化科学知识表示支持知识推理
  → 形成知识支持的产品与结论
  → 对完整智能体系统开展评测
```

弱样本土地覆被制图作为专业工具、真实环境和比较基线进入各章，不单独破坏上述主线。
