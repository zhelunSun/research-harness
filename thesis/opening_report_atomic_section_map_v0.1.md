## 2. 推荐写作单元

每个小节先写以下五项，再扩展为连续文字：

1. **小节职责**：本节回答读者的哪一个问题；
2. **原子论述**：每条只承担一个可判断的陈述；
3. **证据槽位**：指向已有证据包、章节事实或明确的 `[REF-MISSING]`；
4. **边界**：本节不能推出什么；
5. **转接句**：为什么下一节是必要的。

采用的顺序是：

`大纲 → 原子论述 → 证据与引文准入 → 段落展开 → 全文术语与连贯性审计`

这不是先写长文再补引用。引文进入正文前必须经过来源身份、原文定位、论断蕴含关系和 writing
contract 四项检查。

## 3. 逐节原子论述

### 一、论文选题背景及科学意义

#### 1.1 城市森林遥感科学任务的现实需求

- **职责**：说明论文为何从城市森林问题而不是从通用智能体技术出发。
- **原子论述**：领域用户首先提出生态研究、规划或管理问题；这些问题需要转化为城市森林对象、
  可观测变量、数据、空间产品和验证要求；制图、斑块／核心栖息地、廊道／网络和解释环节之间存在
  制品依赖；多源、多时相和跨尺度条件增加方法选择与核验负担。
- **证据槽位**：`urban-forest-remote-sensing-context-2026`；当前保留 `[REF-MISSING]`。
- **边界**：不宣称存在唯一城市森林工作流，也不把所有生态与管理问题纳入论文。
- **转接**：正因为问题不能直接对应单一算法，才需要研究如何组织数据、工具和分析过程。

#### 1.2 智能体为遥感分析提供的新路径

- **职责**：说明智能体为什么可能成为方法入口。
- **原子论述**：传统遥感算法和专业产品仍是分析基础；智能体的作用是从开放问题出发选择并组织
  这些资源；自然语言理解、计划与工具调用提供了新的交互路径；能够调用工具不等于形成科学合理、
  可执行和可追踪的流程。
- **证据槽位**：`geospatial-agent-comparators-2026`；当前保留 `[REF-MISSING]`。
- **边界**：不写成传统遥感方法被替代，也不把工具调用本身作为创新。
- **转接**：面向科研任务的系统还必须处理知识、证据、反馈和验证。

#### 1.3 遥感科学智能体系统

- **职责**：把一般智能体概念收窄到遥感科学分析需要的系统能力。
- **原子论述**：遥感科学分析受观测条件、尺度、方法适用性和验证证据约束；系统需要连接问题
  理解、知识获取、计划、执行、验证与过程记录；现有工作证明若干组件可行，但真实城市森林任务中的
  调整、知识使用、恢复和系统级验证仍缺直接证据。
- **证据槽位**：`scientific-agent-workflow-boundaries-2026` 与 `geospatial-agent-comparators-2026`；
  当前保留 `[REF-MISSING]`。
- **边界**：相邻系统的局限不能直接外推为整个领域普遍失败。
- **转接**：由此得到论文同时研究工作流、知识与系统评测的必要性。

#### 1.4 科学意义与实践价值

- **职责**：说明三项研究合起来增加了什么可研究对象和可使用能力。
- **原子论述**：科学意义落在完整科研过程的可执行、可约束、可追踪和可复现；实践价值落在为
  非遥感专业领域用户提供受边界约束的分析入口；城市森林任务环境是检验方法的深度场景。
- **证据槽位**：由前三节论证汇合，不新增效果性结论。
- **边界**：不写“全面提升”“解决领域全部问题”或正式用户效用已经得到验证。
- **转接**：下一部分分别检查城市森林方法基础和智能体研究能否支持这些要求。
